# VellumFE Privacy Policy

VellumFE runs entirely on your own device and collects no data.

- **No telemetry.** The client sends no analytics, crash reports, usage
  data, or any other information to the project or to third parties.
- **Network connections** are made only to the endpoints you configure:
  the GemStone IV / play.net game servers (direct eAccess mode), a local
  or remote [Lich](https://github.com/elanthia-online/lich-5) proxy, and —
  if you use the optional asset installer (`.jinx`) or map downloads — the
  project's own GitHub-hosted asset repositories.
- **Credentials and settings** (account name, password if you choose to
  save it, layouts, logs) are stored only in local configuration files
  under `~/.vellum-fe/` on your machine and are never transmitted anywhere
  except directly to the game's authentication server when you log in.

Questions? Ask on the [VellumFE Discord](https://discord.gg/6nKhWRTkSN) or
open a GitHub issue.
