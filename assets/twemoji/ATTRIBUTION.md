# Twemoji graphics attribution

The PNG images under `72x72/` are the Twemoji color emoji set, taken from the
maintained community fork:

- Source: https://github.com/jdecked/twemoji (release v17.0.3, `assets/72x72/`)
- Original project: Twemoji, copyright 2019 Twitter, Inc and other contributors
- Fork graphics: copyright Twemoji project contributors (jdecked/twemoji)

The graphics are licensed under the Creative Commons Attribution 4.0
International license (CC-BY 4.0). See `LICENSE-GRAPHICS` in this directory
for the full license text, or https://creativecommons.org/licenses/by/4.0/

These images are embedded into the VellumFE GUI binary and drawn over
monochrome emoji glyphs to render emoji in full color (Settings ->
UI -> Color Emoji). No changes were made to the images themselves.
